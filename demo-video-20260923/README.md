## 撮影・編集方法
`prepare.cjs` は既存main.jsを読み取り、参照先を既存srcへ向けた撮影専用エントリー `filming-main.js` をこのフォルダだけに生成します。本編ファイルには書き込みません。
`director.js` が既存のキーボード操作と更新処理でプレイします。編集上のカットの切り替わりでのみ開始位置を準備しています。徒歩で全行程を連続移動した記録ではありません。
通常と同じカメラ設定・街・ライトで1280×720の実ゲーム画面を描画し、合成Canvasにタイトルと日本語字幕を追加してMediaRecorderで録画しました。
`remux.cjs` は録画したAVC映像を再圧縮せず、分割MP4から通常のシーク可能なMP4へ整理します。最後のタイトルフレームを0.05953秒だけ延長し、全体を54秒にしました。
既存プレビューサーバーはHTTP範囲リクエストに非対応のため、review.htmlはファイル全体を読み込んでから再生します。サーバー設定は変更していません。
